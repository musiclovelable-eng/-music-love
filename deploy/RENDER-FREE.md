# Music Love — Render Free + PostgreSQL

Эта ветка (`render-postgres`) работает без туннеля:

- Render Free web-service публикует полный Next.js-кабинет на `onrender.com`.
- Render PostgreSQL хранит все таблицы.
- Таблица `music_love_storage` хранит содержимое обложек, треков, аватаров,
  отчётов и вложений. Локальная файловая система используется только как временный
  кэш и восстанавливается из PostgreSQL после перезапуска.

## Ограничения бесплатного тарифа

- Web-service засыпает после 15 минут без входящего трафика. Первый запрос после
  этого может занять около минуты.
- Render может перезапустить бесплатный web-service, но данные и файлы в
  PostgreSQL от этого не теряются.
- **Бесплатная база создана 2026-11-02 и истекает 2026-12-02.** После этой даты
  Render требует либо платный апгрейд, либо перенос резервной копии в новую базу.
  Автоматического продления нет.
- Бесплатная база ограничена 1 GB.

## Первичный перенос

Новая PostgreSQL-база должна быть пустой. Скрипт создаёт схему из `drizzle-pg`,
переносит строки с учётом внешних ключей, переносит файлы и проверяет количество
строк, файлов и байт:

```bash
npx drizzle-kit generate --config drizzle.config.ts
DATABASE_URL=postgresql://... \
LOCAL_DATABASE_URL=file:/absolute/path/music-love.db \
LOCAL_STORAGE_DIR=/absolute/path/storage \
npm run migrate:postgres
```

`DATABASE_URL`, пароли и содержимое базы не добавляются в репозиторий.
